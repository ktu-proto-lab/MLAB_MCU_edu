## Directory structure 

### `rtl/`
RTL level simulation.

### `postsyn/`
Post Synthesis functional simulation.

### `postpnr/`
Post Place and Route functional simulation.


## Common files

| File               | Description                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| `files.f`          | File list used by the Xcelium simulator to compile the RTL.                 |
| `restore.tcl.svcf` | Restore waveform configuration in Xrun File -> Source Command Script        |
